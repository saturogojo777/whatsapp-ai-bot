    02 — Why HueForge

    Built for the last 10% nobody automates.

    Most generators stop at pretty swatches. HueForge takes the palette all the way to the pull request.

    Perceptually even ramps

    Lightness is sampled in OKLCH, not HSL. The jump between step 300 and 500 looks the same as the one between 700 and 900 — every time, for every hue.

    Contrast before aesthetics

    A 5×5 matrix grades every pair AA, AAA or fail — with one toggle for large text. Fix accessibility before it becomes a ticket.

    Eight exports, zero copy-paste archaeology

    CSS custom properties, Tailwind v4 @theme, SCSS, JSON, W3C design tokens, an SVG poster, Adobe .ase swatches for Photoshop and Illustrator, and a ready-to-post PNG.

    CSSTailwindSCSSJSONDTCGSVGASEPNG

    Colour-vision simulation

    Preview protanopia, deuteranopia, tritanopia and total colour blindness instantly. Spot the pairs that collapse into one before your users do.

    Private by architecture

    No accounts, no API keys, no telemetry. Generation, contrast maths and PNG rendering all happen on your device — watch the network tab.

    Shareable, deterministic

    Every palette is encoded in the URL hash. Send the link and the exact same five colours — locks included — rebuild on the other side.

    Works offline

    Three.js and every font are vendored in the repo. Load it once and keep working on a plane — no CDN, no flicker, no surprises.

    03 — The workflow

    Three steps. No tabs lost.

    1. 01

      Set the base

      Paste a brand hex, roll a random colour, pick one from the screen with the eyedropper, or drop a logo to extract its dominant hue.

    2. 02

      Shape the ramp

      Try a harmony, lock the two swatches that work, then keep generating until the rest catches up. Undo is a keystroke away.

    3. 03

      Verify and ship

      Scan the contrast matrix, sanity-check colour vision, then copy CSS or export tokens, an SVG poster and a PNG in one click.

    04 — Questions

    Good to know

    Is HueForge really free and private?

    Yes. It is MIT-licensed and runs entirely in your browser. There is no analytics, no account and no server — your palettes and saved library live in localStorage. Share links encode the palette in the URL hash, which is never sent to a server.

    Why OKLCH instead of HSL?

    HSL's "lightness" is not perceptual: hsl(240 100% 50%) is far darker than hsl(60 100% 50%) at the same value. OKLCH is designed so equal numeric changes look equal, which makes ramps predictable. HueForge falls back to gamut-mapped sRGB so the output works everywhere.

    How is contrast measured?

    With the WCAG 2.1 relative-luminance formula, the same one used by browser audits. You can toggle the 3:1 large-text rule. The matrix grades every foreground/background pair in the palette, including the ones you would never use — so nothing hides.

    Can I use the palettes commercially?

    Colours themselves are not copyrightable, and anything you generate here is yours to use. The tool's source is MIT-licensed, so you can also fork and self-host it.

    Does it work offline?

    After the first load, yes — add it to your home screen or open the HTML from disk. The only external asset is Three.js, which is vendored in this repository, so there are no third-party CDN calls at runtime.
